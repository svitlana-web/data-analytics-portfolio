## 📊 Прогресс выполнения и ключевые результаты


### 1. Подготовка данных

* **Предобработка:** 
  * Выполнена очистка нечисловых символов и преобразование типов данных для полей `quantity`, `price_per_unit`, `revenue`.
  * Поле `order_date` приведено к типу `datetime`, сформирован отдельный период `year_month`.
  * Пропуски в категориях (`city`, `payment_method`) заполнены значением `Unknown`, отсутствующие значения `revenue` пересчитаны по формуле с учетом скидок. Итоговый датасет содержит 293 очищенные записи.


### 2. Исследовательский анализ данных (EDA)

* **Ключевые выводы анализа (Pandas):**
  * **Самый популярный товар:** Клавиатура (`Keyboard`, 110 шт.) и Смартфоны (`Smartphone`, 107 шт.).
  * **Лидирующая категория по выручке:** Электроника (`Electronics`) с результатом $398,911 (более 45% от всей выручки).
  * **Пиковый месяц продаж:** Август 2025 года ($97,212).
  * **Средний чек (AOV):** $3,029.67 (медианный чек: $2,589.00).
  * **Топ-клиент по заказам:** Daniel (41 заказ).


### 3. Визуализация данных (Matplotlib & Seaborn)

В рамках этапа графического анализа была построена серия из 5 информативных визуализаций, отражающих ключевые бизнес-метрики e-commerce платформы:

* **Выручка по категориям (Bar Chart с аннотациями):** 
  Продемонстрирована абсолютная лидирующая позиция категории *Electronics* (**$398,911**), выручка которой практически вдвое превышает вторую по объему категорию *Fashion* (**$203,905**).
* **Динамика продаж по месяцам (Line Plot с маркерами):** 
  Выявлена отчетливая сезонность с пиковыми показателями в летний период (**май–август 2025 года**), достигшая максимума в августе (**$97,212**), с последующим спадом к осени.
* **Распределение стоимости заказов (Histogram + KDE):** 
  Установлено преобладание заказов малого и среднего чека (до $2,500). Распределение имеет правостороннюю асимметрию, из-за чего среднее значение (**$3,029.67**) заметно превышает медиану (**$2,589.00**) за счет редких крупных покупок.
* **Структура способов оплаты (Pie Chart):** 
  Визуализировано распределение транзакций по платежным методам: наиболее популярными являются **PayPal (37.9%)** и **Credit Card (32.8%)**, за которыми следует **Cash (28.0%)**.
* **Топ-10 городов по выручке (Horizontal Bar Chart):** 
  Проанализирована география продаж, где лидером по объему выручки выступил **Париж ($150,454)**, за которым следуют Ереван, Мадрид и Рим, что позволяет определить целевые регионы для маркетинговых кампаний.


### 4. Разработка Streamlit-приложения

На базе встроенных средств Streamlit создан интерактивный аналитический веб-сервис для работы с данными интернет-магазина. Приложение структурировано по модульному принципу (Multi-page app) и включает в себя следующий функционал:

* **Загрузка и предобработка данных (`Data Overview`):** 
  Централизованный интерфейс загрузки пользовательских CSV-файлов с автоматической фильтрацией аномалий, конвертацией типов данных и предпросмотром очищенного датасета.
* **Сводная аналитика и KPI (`Analytics & Stats`):** 
  Расчет ключевых бизнес-метрик (Total Revenue, Avg/Median Order Value, Max Check) и агрегированных таблиц по категориям, методам оплаты, месячной динамике и топ-10 городам.
* **Интерактивная визуализация (`Visualizations`):** 
  Вывод полного дашборда из 5 графиков (Matplotlib/Seaborn), наглядно отражающих распределение выручки, тренды и географию продаж.
* **Управление состоянием (`st.session_state`):** 
  Обеспечена бесшовная передача очищенных данных между всеми страницами без повторной загрузки файла.
